2 Music Character

Letter a–g (may include f#). Leave empty to use the genre default key.

Scale character: minor is darker/melancholic, major is brighter. Empty = genre default.

Beats per minute. Empty = genre default (±140 dubstep, ±126 house).

Length of the composition (1 bar = 4 beats). Empty = use the full section template. Example: 8, 16, 32. Up to 280 bars (~5 min at the genre's max tempo).

simple = sparse, airy rhythm · medium = balanced · complex = dense & busy.
